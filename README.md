# webThu

Web luyện trắc nghiệm tiếng Việt xoay quanh tài liệu `LUẬT KINH DOANH.pdf`.

## Chạy local

```bash
npm install
npm run dev
```

## Kiểm tra

```bash
npm test -- --run
npm run build
```

## Phạm vi

- 15 câu hỏi chọn lọc từ ngân hàng 300 câu trong tài liệu nguồn.
- Ba chủ đề: khái quát luật kinh doanh, chủ thể kinh doanh, pháp luật về đầu tư.
- Luồng làm bài một câu một lần, điều hướng câu hỏi, nộp bài và xem lại đáp án.
- Không có đăng nhập, backend hoặc chức năng quản lý đề.

Đây là công cụ tự ôn tập, không thay thế tư vấn pháp lý chuyên môn.
